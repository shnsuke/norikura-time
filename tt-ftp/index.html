Zwift に送る（intervals.icu 経由）

  1. intervals.icu の Settings → Zwift の「Connect」で Zwift と連携しておく（初回だけ）
  2. intervals.icu の Settings → Developer Settings にある API キーを下に貼る
  3. 「登録」を押すと、メニューが intervals.icu の予定表に入り、直近7日分が Zwift に送られる

同じ日付を登録し直すと上書きされます。強度は%FTPで入るので、Zwift と intervals.icu の FTP をこのアプリの FTP に合わせてください。API キーはこの端末のブラウザにだけ保存されます。
